# ADR-001: Name — Hermes Bot

- Status: **Accepted**
- Date: 2026-09-01

## Context

The product is a Grok Bot–style phone client for Nous Hermes Agent. Naming collisions exist with Hermes Mobile, community remotes, and Desktop.

## Decision

The product name is **Hermes Bot**. Bundle identifiers:

- iOS: `app.hermesbot.ios`
- Android: `app.hermesbot.android`

Expo `name` / `slug`: `Hermes Bot` / `hermes-bot`. Avatars are deferred.

## Consequences

All user-facing chrome and repo branding use Hermes Bot. Docs may say “phone client” but not “Hermes Mobile”.
